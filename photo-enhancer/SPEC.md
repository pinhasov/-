# אפיון – "משדרג תמונות" (Photo Enhancer)

## 1. מטרה
כלי עבודה לעורך תמונות: מכניסים עד **100 תמונות בבת אחת**, והאפליקציה משדרגת כל תמונה
לאיכות הגבוהה ביותר שאפשר – הגדלת רזולוציה בבינה מלאכותית (Super Resolution), חידוד פרטים,
תיקון חשיפה וצבע – ומחזירה קבצים מוכנים להורדה (בודדים, ZIP או ישירות לתיקייה במחשב).

## 2. עקרונות מנחים
| עיקרון | משמעות |
|---|---|
| **פרטיות מלאה** | התמונות לא עולות לשום שרת. כל העיבוד נעשה בדפדפן, על המחשב שלך (כרטיס המסך). |
| **בלי עלויות שימוש** | אין API בתשלום, אין מנוי. המודלים ארוזים בתוך האפליקציה. |
| **עובד בלי אינטרנט** | אחרי ההתקנה הכול מקומי. |
| **עבודה בכמויות** | תור של עד 100 תמונות, עיבוד אחת אחרי השנייה, התקדמות חיה, עצירה והמשך. |
| **עברית ומימין לשמאל** | כל הממשק בעברית. |

## 3. משתמשים
משתמש יחיד – עורך התמונות, על מחשב שולחני/נייד (Windows או Mac) עם Chrome / Edge.

## 4. תהליך העבודה (User Flow)
1. פותחים את האפליקציה (לחיצה כפולה על קובץ ההפעלה → נפתח דפדפן).
2. גוררים תמונות לחלון או לוחצים "בחירת תמונות" (JPG, PNG, WebP, BMP). עד 100 בכל סבב.
3. בוחרים הגדרות (או משאירים ברירת מחדל):
   * **רמת איכות**: "מהיר" / "איכות מקסימלית".
   * **הגדלה**: אוטומטי / ×2 / ×4.
   * **גודל מקסימלי לתוצאה** (צלע ארוכה): 4000 / 6000 / 8000 פיקסלים.
   * **שיפורים נוספים**: תיקון חשיפה וניגודיות, חיזוק צבע עדין, חידוד – כל אחד עם מתג.
   * **פורמט שמירה**: JPG איכות 95 / PNG ללא איבוד / WebP.
4. לוחצים "שדרג הכול".
5. כל תמונה מקבלת סטטוס: ממתינה → בעיבוד (עם אחוזים) → מוכנה / שגיאה.
6. בכל תמונה מוכנה: לחיצה פותחת **השוואת לפני/אחרי** עם פס הזזה וזום.
7. הורדה: כל תמונה בנפרד, "הורד הכול כ-ZIP", או "שמור ישירות לתיקייה" (Chrome/Edge).

## 5. דרישות פונקציונליות
| # | דרישה |
|---|---|
| F1 | קליטת עד 100 קבצי תמונה בגרירה או בבחירה. מעבר ל-100 – הודעה, והעודפים לא נכנסים. |
| F2 | תצוגת רשימה עם תמונה ממוזערת, שם, מידות מקור, מידות יעד וסטטוס. |
| F3 | הגדלה ברשת נוירונים ESRGAN ‏(×2 / ×4), בשני מודלים: מהיר וכבד (איכות מקסימלית). |
| F4 | עיבוד באריחים (Tiles) עם חפיפה – כדי לעבד תמונות גדולות בלי לקרוס ובלי תפרים. |
| F5 | שמירה על יחס רוחב/גובה וסיבוב נכון לפי EXIF. |
| F6 | הגבלת גודל התוצאה לצלע מקסימלית; תמונה שכבר גדולה עוברת "שיפור ללא הגדלה". |
| F7 | שיפורים אחרי ה-AI: מתיחת טווח טונאלי אוטומטית, Vibrance עדין, Unsharp Mask. |
| F8 | פלט JPG/PNG/WebP; שם קובץ: `שם-מקורי_enhanced.jpg`. |
| F9 | עצירה באמצע סבב; המשך מהתמונה הבאה; ניסיון חוזר לתמונה שנכשלה; הסרה מהרשימה. |
| F10 | השוואת לפני/אחרי עם פס הזזה. |
| F11 | הורדה בודדת, ZIP לכל התוצאות, ושמירה ישירה לתיקייה. |
| F12 | ההגדרות נשמרות בין הפעלות. |

## 6. דרישות לא-פונקציונליות
* **ביצועים**: עיבוד על כרטיס המסך (WebGL). זמן משוער לתמונה של 1000×1000 ל-×4 במצב מהיר: עשרות שניות,
  תלוי בחומרה. מצב "איכות מקסימלית" איטי פי 3–6 בערך.
* **יציבות**: עיבוד תמונה אחת בכל פעם; שחרור זיכרון בין אריחים ובין תמונות.
* **ממשק לא נתקע** בזמן עיבוד (ויתור על המעבד בין אריח לאריח).
* **דפדפנים**: Chrome / Edge עדכניים (מומלץ). Firefox נתמך בלי "שמור לתיקייה". Safari – מגבלות גודל קנבס.

### צינור העיבוד לכל תמונה
1. **פענוח** – `createImageBitmap` (כולל סיבוב EXIF).
2. **חישוב יעד** – גודל התוצאה = מינימום(מקור × הגדלה, גודל מקסימלי).
   אם צריך, התמונה מוקטנת קודם כך שאחרי ההגדלה תגיע בדיוק ליעד.
3. **הגדלת AI באריחים** – אריחים של 160px עם שוליים של 16px; כל אריח עובר במודל,
   ומרכזו (בלי השוליים) מודבק לקנבס התוצאה – כך אין תפרים.
4. **שיפורים** – מתיחת רמות לפי אחוזונים 0.3%/99.7% של הבהירות (עם תקרה כדי לא "לשרוף"),
   Vibrance שמחזק בעיקר צבעים חלשים, Unsharp Mask עדין.
5. **קידוד** – `canvas.toBlob` לפורמט שנבחר.

## 8. מגבלות ידועות
* HEIC/RAW לא נתמכים ישירות – יש לייצא ל-JPG/PNG/TIFF קודם (TIFF גם הוא לא נתמך בדפדפן).
* במחשב בלי כרטיס מסך תומך – העיבוד יעבור למעבד ויהיה איטי מאוד.
* AI משחזר פרטים "סבירים" ולא את המציאות – בפנים קטנות מאוד או טקסט זעיר ייתכנו אי-דיוקים.

## 9. הרחבות אפשריות בהמשך
* מודל ייעודי לשחזור פנים (GFPGAN/CodeFormer) – דורש שרת Python/GPU.
* הסרת רעש ייעודית לצילומי לילה.
* פריסטים שמורים (חתונות, מוצרים, נדל"ן).
* גרסת שרת בענן לעיבוד מהטלפון.
